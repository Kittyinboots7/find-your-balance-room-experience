# Find Your Balance 객실체험

수 Flow · 목 Grow · 화 Shine, 오행 웰니스 스테이 기획 체험입니다.

정적 HTML/CSS/JavaScript 사이트이며 GitHub Pages에서 공개합니다. 객실의 향과 소리, 기프트와 리추얼 카드를 경험할 수 있습니다.

실제 판매·예약 상품이 아닌 기획 제안용 체험입니다. 객실 배경은 실제 객실 사진을 참고한 AI 연출 이미지이며 배경음은 합성한 자연 소리입니다. 디퓨저는 객실 연출품이며 기프트에 포함되지 않습니다. 이미지와 상표 권리는 각 권리자에게 있습니다.
